AI EARNING BOT 2.0 — iPhone local-first edition

IMPORTANT
- This is a mobile web app/PWA. It stores task and ledger data in Safari local storage on this iPhone.
- It is not a background web crawler and cannot run 24/7 on iOS. iOS suspends web apps in the background.
- It does not log into providers or auto-submit surveys. Survey participation often requires personal opinions, identity checks, consent, attention checks, and truthful answers. Automated completion is only appropriate if a provider expressly authorizes it through documented means.
- It does not send or withdraw money. Withdraw directly inside the provider's official account, then log it here.
- Residence profile is Jamaica. Do not misrepresent US residence or use a VPN to bypass eligibility.

INSTALL ON IPHONE
A PWA must be served over HTTPS (or localhost) to be installable/offline capable. Easiest free option:
1. Upload the contents of this folder to a private GitHub repository.
2. Enable GitHub Pages for the repository (Settings > Pages > Deploy from branch).
3. Open the HTTPS GitHub Pages address in Safari on iPhone.
4. Tap Share > Add to Home Screen.
5. Open from the Home Screen.
6. Use Settings > Export backup regularly. Browser data can be erased by iOS.

NO-CODE LOCAL TEST
Open index.html in a browser to try the dashboard. For full PWA install/offline service worker, use HTTPS hosting.

FEATURES
- Provider directory with official links: Pollrouter Jamaica, Clickworker, UserTesting, Mirats Rewards, ySense.
- Add and track opportunities across surveys, AI training, testing, data entry and research.
- Track pending and approved rewards.
- Log manual withdrawals to PayPal, Payoneer or bank methods that the provider actually supports.
- Export/import JSON backups.
- Daily discovery target is a planning goal, not a promise of 100 available or completed tasks.

SECURITY
- No passwords, bank account numbers, card numbers or verification codes are requested or stored.
- Keep the hosted URL private if the GitHub repository is private; GitHub Pages publishing visibility depends on your plan/repository settings. Do not upload private personal information.
